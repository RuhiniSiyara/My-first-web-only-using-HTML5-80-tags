01. What is the Internet?

  • Have you ever wondered what happens when you type a web address into your browser and hit Enter? How does your device know where to fetch the content?
  • What invisible processes work behind the scenes to display this website on your screen?

The Internet: A Network of Networks

  • What is the Internet...It is a global network of interconnected computers and devices that communicate using standardised protocols to share information, resources, and services.
  • The intrnet is not a single line or a connection; it is a huge collection of interconnected networks,like a ball of yarn but never get tangled , because of the uniqueness of the IP adressess, So we called it Network of Networks.
  • The concept originated in the 1960s with ARPANET, a U.S. military project designed to create a decentralized communication system.
  • These networks include private, public, academic, business, and government networks, all linked together by a variety of electronic, wireless, and optical networking technologies.

02. How the Internet works

  • Let me explain it In 5 Steps...

    1. You type a web address (URL) into your browser and hit Enter.
      When you open a website (like google.com), your device asks for the page.
      And then your request first goes through your ISP (Dialog, SLT, Airtel, etc).
      They give you access to the Internet.

    2. Your device sends a request to a DNS server to translate the URL into an IP address.
      Computers don’t understand names like google.com.
      They only understand IP addresses (like 142.250.190.14).
      DNS works like a phone book – it translates website names into IP addresses.

    3. The DNS server responds with the IP address of the web server hosting the website.


    4. Your device sends a request to the web server using the IP address.
      Once your device knows the IP address, it connects to the server that hosts the website.
      Example: Google’s server stores the search page.

    5. The web server processes the request and sends back the requested web page to your browser, which then displays it on your screen.
      6. The information (text, images, video) travels across the Internet in small pieces called packets.
      These packets move through routers (like traffic signals) to reach your device.
      Your browser (Chrome, Edge, etc.) reassembles the packets and shows you the full web page.

03. Main services in the Internet

The main services provided by the Internet include...

  • World Wide Web (WWW): A system of interlinked hypertext documents accessed via web browsers.
  • Email: A method of exchanging digital messages over the Internet.
  • File Transfer Protocol (FTP): A standard network protocol used to transfer files between a client and server.
  • Streaming Services: Platforms that allow users to watch videos or listen to music in real-time without downloading.
  • Social Media: Websites and applications that enable users to create and share content or participate in social networking.
  • Cloud Computing: The delivery of computing services over the Internet, allowing for data storage and processing on remote servers.
  • Online Gaming: Multiplayer games that are played over the Internet.
  • VoIP (Voice over Internet Protocol): A technology that allows for voice communication and multimedia sessions over the Internet.
  • Search Engines: Tools that help users find information on the Internet by indexing and ranking web pages.
  • E-commerce: Buying and selling goods and services over the Internet.

05. Role of Web Browsers

  • Have you ever wondered how you can access and view websites on the Internet? The answer hits Web Browsers...
  • Web browsers are a normal software applications that allow users to access and navigate the World Wide Web...
  • Its main role to FETCH, INTERORET, AND DISPLAY WEB CONTENT from the WWW.

The Core Functions of a Web Browser

  1. Requesting and Receiving Data:
      When you enter a URL (https://www.google.com) or click on a link, the browser sends a request to the appropriate web server to retrieve the web page or resource.
  2. Interpreting HTML/CSS/JavaScript:
      The browser processes the HTML code, CSS styles, and JavaScript scripts to render the web page correctly.
  3. Rendering Web Pages:
      The browser displays the web page on your screen, allowing you to interact with it. This includes rendering text, images, videos, and other multimedia elements.
  4. Navigating Between Pages:
      Browsers provide navigation features such as back and forward buttons, bookmarks, and history to help users move between different web pages easily.
  5. Managing Security and Privacy:
      Browsers implement security measures like HTTPS encryption, pop-up blockers, and privacy settings to protect users from malicious websites and data breaches.
  6. Supporting Extensions and Plugins:
      Many browsers allow users to install extensions or plugins that enhance functionality, such as ad blockers, password managers, and developer tools.

06. What is DNS and why it is important

  • DNS stands for Domain Name System...
  • Its primary role is to translate humanfriendly domain names like 142.250.191.78 ,that computers use to identify and communicate with each others on a network.

Why DNS is Important ?

    Without DNS, we'd have to memorize a long string of numbers for every website we wanted to visit. DNS makes the internet much more accessible and user-friendly by abstracting away the complex numerical addresses.
  1. User-Friendliness:
      DNS allows you to use simple, memorable names instead of a series of numbers.
  2. Scalability:
      The DNS system is distributed across countless servers worldwide, which allows it to handle the immense volume of daily web traffic and the millions of new websites being created.
  3. Flexibility and Reliability:
      If a website's server moves or its IP address changes, the DNS record can be updated without the user ever knowing.
      This ensures that the website remains accessible. The distributed nature of DNS also provides redundancy; if one server fails, others can still resolve the address.
  4. Security:
      DNS can be used to block malicious websites by preventing a domain name from resolving to a known harmful IP address.

      However, DNS itself can be a target for attacks, so security measures like DNSSEC (DNS Security Extensions) have been developed to protect against such threats.
