01. Purpose of each HTML tag

HTML (HyperText Markup Language) is the standard language used to create and design web pages. It consists of various tags that define the structure and content of a webpage. Here are some of the most commonly used HTML tags and their purposes:

  1. <!DOCTYPE html>: Declares the document type and version of HTML being used.
  2. <html>: The root element that contains all other HTML elements.
  3. <head>: Contains meta-information about the document, such as the title, character set, and links to stylesheets or scripts.
  4. <title>: Sets the title of the webpage, which appears in the browser tab.
  5. <meta>: Provides metadata about the HTML document, such as character encoding and viewport settings.
  6. <link>: Links external resources like stylesheets to the HTML document.
  7. <body>: Contains the main content of the webpage that is visible to users.
  8. <h1> to <h6>: Define headings, with <h1> being the highest level and <h6> the lowest.
  9. <p>: Represents a paragraph of text.
  10. <a>: Creates hyperlinks to other webpages or resources.
  11. <img>: Embeds images into the webpage.
  12. <ul>, <ol>, <li>: Create unordered (bulleted) and ordered (numbered) lists, with <li> defining each list item.
  13. <div>: A container element used to group other elements for styling or layout purposes.
  14. <span>: An inline container used to apply styles or scripts to a specific quatation of text.
  15. <br>: Inserts a line break within text content.
  16. <hr>: Creates a horizontal rule (line) to separate content.
  17. <form>: Defines a form for user input, such as text fields, checkboxes, and buttons.
  18. <input>: Represents an input field within a form.
  19. <button>: Creates a clickable button.
  20. <table>, <tr>, <td>, <th>: Used to create tables, with <tr> defining table rows, <td> defining table cells, and <th> defining header cells.

02. When and how to use HTML tags

HTML tags should be used to structure and format the content of a webpage appropriately. Here are some guidelines on when and how to use HTML tags:

  • Use semantic tags (like <header>, <nav>, <main>, <footer>) to define the different sections of your webpage for better accessibility and SEO.
  • Use heading tags (<h1> to <h6>) to create a clear hierarchy of content, with <h1> for the main title and subsequent headings for sub-sections.
  • Wrap text content in <p> tags to create paragraphs, ensuring proper spacing and readability.
  • Use <a> tags to create hyperlinks, ensuring the href attribute points to a valid URL or resource.
  • Embed images using the <img> tag, providing the src attribute with the image URL and alt attribute for accessibility.
  • Group related elements using <div> or <section> tags for better organization and styling.
  • Use lists (<ul>, <ol>, <li>) to present information in a structured manner, making it easier to read and understand.
  • Incorporate forms using the <form> tag for user input, ensuring each input field is appropriately labeled.
  • Avoid using deprecated tags (like <font>, <center>) and instead use CSS for styling and layout purposes.
  • Always close tags properly to ensure the HTML document is well-formed and valid.
  • Use comments (<!-- comment -->) to annotate your code for better understanding and maintenance.

03. Example HTML code snippet

Here is a simple example of an HTML code snippet that demonstrates the use of various HTML tags:

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Sample HTML Page</title>
    <link rel="stylesheet" href="styles.css">
</head>
<body>
    <header>
        <h1>Welcome to My Sample HTML Page</h1>
        <nav>
            <ul>
                <li><a href="#section1">Section 1</a></li>
                <li><a href="#section2">Section 2</a></li>
            </ul>
        </nav>
    </header>

    <main>
        <section id="section1">
            <h2>Section 1</h2>
            <p>This is a paragraph in section 1.</p>
            <img src="image.jpg" alt="Sample Image">
        </section>

        <section id="section2">
            <h2>Section 2</h2>
            <p>This is a paragraph in section 2.</p>
            <ul>
                <li>Item 1</li>
                <li>Item 2</li>
                <li>Item 3</li>
            </ul>
        </section>

        <form action="/submit" method="post">
            <label for="name">Name:</label>
            <input type="text" id="name" name="name"><br><br>
            <button type="submit">Submit</button>
        </form>
    </main>

    <footer>
        <p>&copy; 2025 My Sample HTML Page</p>
    </footer>
</body>
</html>
